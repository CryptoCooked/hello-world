# Version 3.0 plan

Latest plan. Replaces docs/STEP9.md.

## Goal

A lean repo showing only what the app runs on; a shared structure so new characters plug in; a simpler chat info that every character fully understands.

## Structure (v3.0)

- `characters/silas/`: who Silas is (from `silas-character/`). The only character-specific part.
- `function/`: how any character behaves. Shared.
- `chat-info/`: `chat-info.md` (what chat info holds and its rules) and `chat-info.js` (its screen code). Shared.
- `awareness/`: what the app is, how it works, what's coming, and the live facts per message. Shared.
- `assembly/`: puts one character together with function, chat-info and awareness for each reply (from `the-app/putting-silas-together/`).
- Everything the app doesn't need moves to the branch `archive-2026-10-22`. main keeps only what runs, the checks, `TODO.md`, one README and `CLAUDE.md`.

## Chat info

Chat info contains only:

- Ask [character] private
- Money
- Dates
- Agreements: from the chat (free); uploaded formal agreement such as a settlement or partnership agreement (paid, coming)

Money, dates and agreements can each be removed per item or cleared, and both people must agree: one asks, the other confirms, either can cancel.

### Moves out of chat info

- A separate Settings screen (gear icon): close, block, wipe, change their name, new-PIN link, your link, change my PIN, sign out, install, notifications.
- Into `function/`: 20 answers per chat per day in total, shared and private together, said once when it runs out. The character asks early, once and naturally, how the two people know each other, and the answer sets the relationship.
- Deleted: the "How you know them" setting, the daily-limit section, "Coming soon".
- The AI switch explanation goes next to the switch.
